# HR Employee Analytics Dashboard

## 📊 Project Overview

HR Employee Analytics is an interactive Power BI dashboard designed to analyze employee workforce data and provide insights into salary, performance, hiring trends, work mode, and employee attrition.

The project uses a synthetic dataset containing 400 employee records and is designed as a lightweight Data Analyst portfolio project.

## 📌 Dashboard Pages

### 1. HR Overview

- Total Employees
- Average Salary
- Attrition Rate
- Average Performance
- Employees by Department
- Employee Hiring Trend
- Gender Distribution
- Work Mode Distribution

### 2. Salary, Performance & Attrition

- Average Salary by Department
- Average Salary by Job Role
- Experience vs Salary
- Attrition by Department
- Performance Rating Distribution
- Attrition by Work Mode
